4.0 — Rebuilt from the ground up
12 August 2026

The application layer has been rewritten. The previous build had a fault that threw on load, which meant no tool actually ran; the catalogue also counted a lot of duplicated and placeholder entries. This release replaces all of it with 124 tools that work, each verified by an automated test suite.

New

  • 124 working tools across 12 categories, every one with settings written for its own job.
  • Each tool now has its own address, such as /merge-pdf/.
  • A rebuilt interface that works properly on phones.
  • Three themes: dark, light and midnight.
  • An assistant that finds a tool from a plain description of the task.
  • An automated suite that opens every tool and checks its output.

Fixed

  • Tool pages threw updateProcessBtn is not defined on load, so nothing ran.
  • The mobile layout rendered at desktop width inside a phone viewport.
  • Many tools were wired to unrelated functions — the CSS minifier generated box shadows.
  • The assistant registered its click handler twice, so it opened and shut immediately.
  • Icons came from a content network that was failing, leaving blank squares.
  • The offline service worker had a fault that stopped it caching anything.
  • Uploaded file thumbnails vanished the moment they appeared.

Removed

  • Duplicate catalogue entries — four separate listings pointed at one UUID generator.
  • Placeholder entries that had a name but no implementation.
  • Tools that cannot work without a server, rather than shipping ones that quietly fail.

Suggestions and bug reports are welcome on GitHub.
