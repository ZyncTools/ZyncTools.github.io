Support the project

ZyncTools is free and always will be. No ads, no paywalls, no watermarks, no account. If it saved you some time, here are a few ways to help.

Star it on GitHub Free, takes a second, and it is the main way people find the project. Report a bug or request a tool Knowing what is broken or missing is worth more than money. Tell someone Share it with anyone who still uploads private documents to random sites. Sponsor on GitHub Covers the domain and the time. Entirely optional.

Where the money goes

There is not much to spend it on, which is rather the point. The site is static files on GitHub Pages, so hosting is free. There are no servers to run, because no file is ever processed on one. The costs are the domain and the hours.

What we will not do

Add advertising, sell usage data, gate tools behind a subscription, or watermark your output. If the project ever needs money badly enough to consider those, it will be shut down instead.

Either way, thank you for using it — and for reading this far.
